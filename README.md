# 太阳系 3D 交互模型

用真实轨道要素驱动的太阳系模型。Vite + Three.js，原生 JS。

## 跑起来

```bash
npm install
npm run dev
```

其他命令：

```bash
npm run verify   # 跑 28 项轨道与自转校验
npm run build    # 生产构建
```

## 操作

- **点击天体** → 相机飞过去锁定跟随，右侧滑出资料面板；`ESC` 或点空白处解除
- **资料面板底部「登陆」** → 转场进入该天体地表（仅限有固体表面的天体）
- **底部时间条** → 播放/暂停、倒放、倍率滑块；点日期可直接输入跳转
- **左下角** → 可视比例 / 真实比例 切换
- 键盘：`空格` 暂停 · `[` `]` 倍率 · `R` 倒放 · `M` 切尺度 · `L` 名称标签 · `0~8` 聚焦
- 鼠标：滚轮缩放 · 左键旋转 · 右键平移

地表场景里：点击画面进入第一人称，`WASD` 移动 · `空格` 跳跃 · `Shift` 加速 · `ESC` 交还鼠标。

## 这个模型认真在做的事

**轨道是真的。** 用 JPL / Standish 的《Keplerian Elements for Approximate Positions of the Major Planets》六要素加每世纪变化率，牛顿迭代解开普勒方程 `M = E - e·sinE`。`npm run verify` 会核对这些：

| 校验 | 结果 |
|---|---|
| 2003 年火星大冲 | 计算得 2003-08-28 18:00 UTC，史实 17:59 UTC |
| 最近距离 | 0.37303 AU，史实 0.37272 AU |
| 地球恒星年 | 365.2564 天（三个不同起点） |
| 开普勒方程残差 | ≤ 4.4×10⁻¹⁶ rad，最多 3 次迭代 |
| 转轴倾角（八颗行星） | 与 NASA 标称值吻合到 0.01° 内 |
| 伽利略卫星拉普拉斯共振 | n₁−3n₂+2n₃ = −2×10⁻⁵ °/天 |

**自转轴取向是真的。** 由 IAU 给出的自转极 (α₀, δ₀) 经黄赤交角转到黄道坐标系施加，不是简单绕 Y 轴旋转。天王星因此真的"躺着滚"，金星逆行。

**地表的手感是算出来的，不是调出来的。** 跳跃给固定起跳速度 4.2 m/s，高度 `h = v²/2g`
与滞空 `t = 2v/g` 都由该天体的真实重力自然决定 —— 月球上跳 5.44 m、滞空 5.2 秒，
火星上 2.37 m / 2.3 秒。日照强度按到太阳的真实距离做平方反比衰减，
火星是地球的 43%、木卫二只有 3.7%。

**尺度作弊是显式的。** 距离压缩、半径放大、卫星轨道系数全部从 `src/core/scale.js` 读取，并实时显示在左下角。切换到 1:1 真实比例时，两套映射之间做连续插值而非瞬切——相机不动，你是看着星球缩下去的。

## 目录

```
src/core/     引擎（时间、尺度、相机、渲染器、贴图、后处理）
src/bodies/   开普勒轨道、自转、材质、环、大气
src/ui/       HTML overlay 界面
data/         轨道要素、天体参数、卫星、探测任务
scripts/      验收脚本
public/textures/  贴图
```

数据与逻辑分离：引擎代码不硬编码任何具体天体的数值或文案，全部来自 `data/*.json`。

## 已知限制

- 月球与火星的法线图是**运行时从漫反射图亮度生成的**，属于视觉近似，不是真实地形高程。Solar System Scope 的贴图包只提供了地球的法线图。详见 `public/textures/ATTRIBUTION.md`。
- 伽利略卫星与土卫六的历元平黄经是近似值，未经星历核对；轨道尺寸、周期、共振关系是准确的。
- 伽利略卫星与土卫六没有贴图（贴图包未提供），目前是纯色球。
- 天体的 `narrative` 介绍文案目前是占位文本。
- **地表地形是程序化噪声，不是真实 DEM。** 全球高程图在第一人称尺度下没有可用信息量：
  2K 全球图在火星上是 10.4 km/像素，一个 3 km 见方的场景只跨 0.29 个像素；
  即便换成 MOLA 最好的全球产品（463 m/px）也只有 6.5 个像素。真要用真实地形，
  需要着陆点局部的 HiRISE DTM（~1 m/px）量级的数据。`terrain.js` 保留了替换接口。
- 登陆是**转场切换到独立场景**，不是从太空到地表的无缝过渡。两套场景单位制差九个数量级
  （轨道 1 单位 = 100 万 km，地表 1 单位 = 1 米），这是刻意的取舍。
